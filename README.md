# Fight Timer — web build

Round timer for boxing, MMA and kickboxing. Bell on every round, clap at ten
seconds left, works offline once loaded.

**Live: <https://zemanskym.github.io/fight-timer-web/>**

Add it to your home screen (iOS: Share → Add to Home Screen; Android: Install app)
and it runs full-screen and offline.

## What this repository is

Generated output only — the `dist/` build of the app, published so the web version
has a stable URL. It is not the source; do not send pull requests here. Every file
except `index.html`, `sw.js` and `manifest.webmanifest` carries a content hash in
its name, so the whole tree is replaced on each release.

Privacy policy: <https://zemanskym.github.io/fight-timer-privacy/>
